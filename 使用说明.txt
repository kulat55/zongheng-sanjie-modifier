纵横三界 修改器（个人测试版）使用说明
================================================

快速开始：直接双击「纵横三界修改器.exe」（单文件，无需安装 Python），
点一个按钮进入对应工具：内存修改器（含一键无敌） / 存档编辑器（含装备管理）。

文件夹内文件：
- 纵横三界修改器.exe    —— 打包好的单文件程序（双击即用，含全部功能）
- launcher.py           —— 启动器源码（两个工具的入口菜单）
- memory_trainer.py      —— 内存修改器源码（含一键无敌）
- save_editor.py         —— 存档编辑器源码（含装备管理）
- equipment_table.json   —— 装备全量表（986 件，已打包进 exe，也可单独使用）
- 启动内存修改器.bat / 启动存档编辑器.bat —— 备用：用 Python 源码直接跑（需装 Python3）

------------------------------------------------
〇、一键无敌（内存修改器内）
------------------------------------------------
1. 附加游戏进程后，点「开启无敌」：
   - 程序自动读取存档里的角色 HP，全内存扫描定位；
   - 提示后回游戏让角色被打掉一点血，点「是」自动校准；
   - 校准后自动开启：HP 被锁定为满血 = 无敌。
2. 再点按钮变成「关闭无敌」→ 停止锁定，恢复正常受伤。
3. 每次重开游戏都要重新定位一次（内存地址每次启动都会变），
   「重新定位 HP」可随时重来；「满血值」默认自动读档，可手动改。
4. 若存档读不到 HP（比如还没进过游戏），会弹窗让你手动输入当前 HP 和满血值。

------------------------------------------------
〇〇、简易模式（不会扫描也能用）
------------------------------------------------
不想学扫描？在内存修改器里点「简易模式（血量/蓝量/金币/灵魂）」：
1. 打开后直接显示 4 行：血量 / 蓝量 / 金币 / 灵魂
2. 每行先点「定位」：程序自动读档并扫描，按提示让数值变一下
   （血量→被打一下；蓝量→放个技能；金币→花点金币；灵魂→消耗点灵魂），点「是」完成定位
3. 定位成功后：
   - 输入新值点「写入」→ 直接改（比如血量写 999999）
   - 勾「锁定」→ 数值一直保持（再掉血也会被拉回来）
4. 「当前:」会自动刷新显示游戏里的实时数值；地址每次重开游戏都要重新定位。

------------------------------------------------
一、内存修改器（实时数值）
------------------------------------------------
1. 先启动游戏《纵横三界》，进入游戏并让数值出现在界面上。
2. 双击「启动内存修改器.bat」或从 exe 进入（首次可能需右键→以管理员身份运行）。
3. 程序会自动识别“纵横三界”进程（不会误选修改器自己）；点「附加进程」。
   （勾选「自动附加」后，游戏启动会自动挂上，不用手动点）
4. 两种扫描方式：
   a) 知道当前数值（如灵魂 1000）：输入数值，类型选「全部」，点「首次扫描」；
   b) 不知道数值：直接点「未知初始值」快照全部候选，
      回游戏让数值变化后，用「变大/变小/没变」过滤缩小范围。
   （灵魂=整数(int64)、生命/攻击等可能是整数或小数(double)，类型选「全部」一次扫全）
5. 回游戏让数值变化，再点「再次扫描」选「变小了/变大了/没变」逐步缩小。
6. 结果列表选中地址 → 输入新值 → 「写入选中」；「冻结选中」可锁定数值；
   「自动刷新」会每 0.5 秒刷新列表数值，方便观察。
7. 地址可「保存地址表/载入地址表」，下次直接使用。
8. 「仅可写内存」默认勾选：只扫可写区域，更快、误报更少（游戏数值都在可写区）。

已知建议：
- 灵魂 soul_count、金币 gold 用 int64 扫；HP/攻击用 double 或 int64 都试。
- 首次全内存扫描可能需要十几秒到一分钟，属正常。
- 未知初始值扫描候选超过 150 万条会自动停止，此时建议改用“输入已知数值”方式。

------------------------------------------------
二、存档编辑器（改存档文件）
------------------------------------------------
1. 游戏里先进任意存档（新建或已有），退出游戏（或切到主菜单）。
2. 双击「启动存档编辑器.bat」。
3. 程序会自动定位存档目录：
   %APPDATA%\Godot\app_userdata\造梦西游 · 圆梦计划：纵横三界篇 (4.5)\saves
   （找不到可点「浏览…」手动选 saves 目录）
4. 点槽位行 → 「载入选中槽位」，改数值 → 「保存修改」。
   - 主属性：等级、经验、金币、灵魂、2P灵魂、灵魂上限、怒气、已解锁关卡/恶魔关卡、当前地图
   - 角色属性：生命/法力/攻击/防御/暴击/闪避等（player_stats，1P 与 2P 分开）
   - 背包数量：选中道具行，输入新数量点「应用到选中道具」
5. 每次保存前自动备份为 save_N.json.backup_手工，出错可手动恢复。
6. 其他功能：
   - 「装备管理…」：浏览游戏全部 986 件装备/道具（搜索按 名字/id/类型/品质/所属），
     选中后「加入背包」（可填数量，可堆叠道具自动合并）或「直接穿上」
     （自动匹配槽位：武器/法宝/防具/饰品/时装/头衔，换下的旧装备自动回背包）。
     改动同步写 backpack_items + category_states + role_equipment，保存时自动重算 guard。
     装备表数据来自反编译的 AllEquipment.gd（同目录 equipment_table.json）。
   - 「完整JSON编辑」：直接改整个存档 JSON（任务 missions、角色装备 role_equipment、
     分类页 category_states、技能冷却等任意字段），应用后校验并重算 guard。
   - 「合规检查」：对照游戏 SAVE_LIMITS 检查当前数值是否超安全水位。
   - 「复制槽位…」：把当前存档复制到其他槽位（原档自动备份）。
   - 「删除槽位」：删除前自动备份为 .backup_删除。
   - 「存档码历史…」：查看游戏记录的 save_history.json 存档码历史，可一键导入回槽位。
   - 「导出存档码」：生成 ZM2. 存档码（可在另一台设备上「导入存档码」使用，
     与游戏内存档码系统完全兼容，已用真实 Godot 引擎双向互解验证）。

安全水位（超过会怎样？）：
- 本游戏反作弊默认关闭（CHEAT_CHECK_ENABLED=false），存档不会被清除。
- 建议仍把数值控制在合理范围：等级≤80、灵魂≤1万亿、攻击≤50万、
  生命/法力≤2000万、防御/法防≤20万、暴击率≤300、闪避≤150、道具堆叠≤99999。
- 存档中 guard 字段会在保存时自动按游戏算法重算（MD5），保证与游戏自算一致。

------------------------------------------------
三、技术说明（开发者向）
------------------------------------------------
- 游戏引擎：Godot 4.5，pck 加密目录已解包、脚本已反编译（见 .godot_tool 目录）。
- 存档为明文 JSON，路径 user://saves/save_%d.json（槽位 1-24）。
- guard = {level,soul,soul2p,stats}，每项 = md5(规范化JSON(值)+"|zhxys-0.67-save-guard")；
  规范化 = JSON.stringify → parse → stringify（整数变 x.0、键按 ASCII 排序），
  编辑器已按真实 Godot 4.5.2 引擎行为复刻并逐项比对通过。
- 存档码 ZM2 格式：SHA256前4字节 + flag + ZSTD压缩体 + XOR流，XOR 盐
  "ZMXY-SaveCodec-v2-20260926#<计数器>"，已与 Godot 引擎双向互解验证。
- 装备系统（来自反编译 AllEquipment.gd / Global.gd / UniformSystem.gd）：
  - 槽位：0武器 / 1法宝 / 2防具 / 3饰品 / 4时装 / 5头衔 / 6双刀（玉兔/哪吒/白龙/沙僧特殊武器）；
  - 背包条目 = {item_data, category, page, slot_index}（20页×25格），
    category 按类型分 equipment/item/fashion/book；category_states 同步显示缓存；
  - 数值随机字段（randi_range/snapped(randf_range)）按游戏 create_stable_item_data 取下限固化。
- 一键无敌原理：读档取 player_stats.Hp/max_Hp → 全类型（int32/int64/float/double）
  扫描等于当前 HP 的可写内存地址 → 掉血后按「变小了」过滤（精确到 1-4 个地址）→
  后台线程每 80ms 把这些地址写回满血值；关闭开关即停止写入 = 恢复受伤。
- exe 打包：PyInstaller --onefile --windowed，equipment_table.json 用 --add-data 打入
  （运行时经 sys._MEIPASS 定位），tkinter + zstandard 一并打包，无需安装 Python。
