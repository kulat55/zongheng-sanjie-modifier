# 造梦西游-纵横三界-修改器

> **个人测试专用・请勿商用 / 请勿用于他人作品**
> 针对自研 Godot 4.5 单机游戏《纵横三界》（造梦西游・圆梦计划：纵横三界篇）的本地修改器。
> 双击 exe 即用，无需安装 Python。



***

## 功能总览



| 模块    | 功能        | 说明                                      |
| ----- | --------- | --------------------------------------- |
| 内存修改器 | 数值扫描      | 首次扫描 / 再次扫描 / 未知初始值 / 仅可写内存 / 冻结，通用型    |
| 内存修改器 | **一键无敌**  | 自动定位 HP → 开启 = 锁满血，关闭 = 恢复正常受伤          |
| 内存修改器 | **简易模式**  | 不会扫描也能用：直接显示 血量 / 蓝量 / 金币 / 灵魂，定位→写入→锁定 |
| 存档编辑器 | 槽位管理      | 自动识别存档目录，载入 / 复制 / 删除槽位，自动备份            |
| 存档编辑器 | 属性修改      | 等级、经验、金币、灵魂、HP/MP、攻击、防御、暴击、闪避等          |
| 存档编辑器 | 背包 / 装备管理 | 986 件装备全量表，可加背包、可装备到角色                  |
| 存档编辑器 | 存档码       | 一键导出存档码（可分享 / 回滚），支持导入                  |
| 存档编辑器 | 合规检查      | 修改前自动检查数值是否越界（避免游戏读取异常）                 |

## 快速开始



1. 下载 `纵横三界修改器.exe`（单文件，约 13.6 MB，Windows x64）。

2. 双击运行 → 出现启动器窗口，三个按钮：

* **内存修改器**（扫描数值 / 一键无敌 / 简易模式）

* **存档编辑器**（改存档 / 装备管理）

* **退出**

1. 先启动游戏进入存档，再打开对应工具使用。



***

## 内存修改器

### 0. 附加进程



* 打开「内存修改器」后，点 **刷新进程**，在下拉框选择游戏进程，点 **附加进程**。

* 提示变为「已附加」即可开始。

### 1. 一键无敌（推荐新手用）



1. 附加进程后点 **开启无敌**：

* 自动读取存档角色 HP → 全内存扫描定位（约几秒）；

* 按提示回游戏让角色**被打掉一点血**，回来点「是」自动校准；

* 校准完成后 HP 被锁定为满血 = **无敌**。

1. 再次点击按钮变为 **关闭无敌** → 停止锁定，恢复正常受伤。

2. 每次重开游戏需要重新定位（内存地址每次启动都会变），可点「重新定位 HP」。

3. 「满血值」默认自动读档，也可以手动填。

### 2. 简易模式（不会扫描也能用）

在内存修改器窗口点 **「简易模式（血量 / 蓝量 / 金币 / 灵魂）」**：



1. 窗口显示 4 行：**血量 / 蓝量 / 金币 / 灵魂**。

2. 每行点 **定位** → 按提示让对应数值变化一次（被打一下 / 放个技能 / 花点金币 / 消耗点灵魂）→ 点「是」。

3. 定位成功后：

* 输入新值 → **写入**（例如血量填 `999999`）；

* 勾选 **锁定** → 数值持续保持，掉血也会被拉回来。

1. 「当前:」列会自动刷新游戏内实时数值。

### 3. 通用数值扫描（进阶）



* 输入数值，选类型（全部 /int32 /int64 /float/double），点 **首次扫描**；

* 数值变化后选「变大了 / 变小了 / 没变 / 改变了」→ **再次扫描** 收敛；

* 不确定初始值可用「未知初始值」；

* 结果列表可 **冻结** 选中地址（持续写回）。



***

## 存档编辑器

### 1. 载入存档



* 打开后自动识别存档目录并列出槽位，选中槽位点 **载入**；

* 修改前自动生成 `.bak` 备份（历史记录可回滚）。

### 2. 修改属性



* 直接改等级、金币、灵魂、HP/MP、攻击等字段，点 **保存**；

* 保存时自动重算 `guard` 校验码，游戏可正常读取。

### 3. 装备管理



* 打开「装备管理」→ 986 件装备全量列表（id / 名称 / 类型 / 品质 / 归属 / 攻 / 售价）；

* 选中装备 → **添加到背包**（自动找空位，堆叠类自动叠加）；

* **装备到角色** 直接穿到当前 / 指定角色身上。

### 4. 存档码



* **导出**：把整个存档压缩编码为一段字符串，可保存或分享；

* **导入**：粘贴存档码恢复存档（含校验，防篡改）。

### 5. 合规检查



* 保存前自动检查等级、属性、数量是否越界并给出提示，避免改过头导致存档读不出来。

## 常见问题（FAQ）



| 问题               | 解决                             |
| ---------------- | ------------------------------ |
| 进程列表里没有游戏        | 先启动游戏再刷新；本工具是 64 位进程，只列 64 位进程 |
| 定位后候选很多 / 过滤后无候选 | 确认数值确实变化了；变化幅度要符合所选方向；可重新定位    |
| 重新进游戏后修改失效       | 内存地址每次启动都变，需重新附加 + 重新定位        |
| 想还原存档            | 存档编辑器历史记录里点备份项回滚，或导入之前导出的存档码   |
| 杀毒软件报警           | 内存读写类工具可能被误报，加入信任即可（源码公开可自行审查） |
